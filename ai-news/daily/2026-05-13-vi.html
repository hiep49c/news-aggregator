1 Microsoft MDASH: Hệ Thống Bảo Mật Đa Tác Tử Phát Hiện 16 Lỗ Hổng Mới

NguồnMicrosoft Security Blog Ngày2026-05-12 URLmicrosoft.com/security/blog/...
Tóm tắt

Microsoft phát hành MDASH — hệ thống điều phối 100+ agent AI chuyên biệt, phát hiện 16 lỗ hổng mới trong Windows networking stack (4 Critical RCE). Đạt 88.45% trên CyberGym benchmark — cao nhất bảng xếp hạng.

Phân tích kỹ thuật
  • Kiến trúc: Pipeline 5 giai đoạn (Prepare → Scan → Validate → Dedup → Prove) với ensemble nhiều model và agent chuyên biệt.
  • Đổi mới: Cơ chế "debate" đa tác tử — auditor phát hiện, debater phản biện, tăng độ tin cậy khi không bác bỏ được.
  • Benchmark: 96% recall trên 5 năm MSRC cases (clfs.sys); 100% recall (tcpip.sys). 21/21 bug cài sẵn, zero false positive.
  • Model-agnostic: Đổi model chỉ cần thay config.
Tại sao quan trọng

Hệ thống AI phát hiện lỗ hổng production-grade đầu tiên trên mã nguồn đóng. Chuyển AI security từ "nghiên cứu" sang "ship patch." Kiến trúc multi-agent debate là template cho verification domains khác.

So sánh
  • vs. DARPA AIxCC (2024): Cùng team, mở rộng từ OSS sang kernel proprietary code.
  • vs. Anthropic Mythos: Mythos nhận diện điểm yếu; MDASH đi xa hơn với proof construction end-to-end.

2 Anthropic "Dreaming" — Agent Tự Cải Thiện Giữa Các Phiên

NguồnReuters / Anthropic Ngày2026-05-06 URLreuters.com/...
Tóm tắt

Anthropic ra mắt "Dreaming" trong Claude Managed Agents — tiến trình nền chạy giữa các phiên, xem lại tối đa 100 phiên trước, trích xuất pattern, và xây dựng bộ nhớ dài hạn có cấu trúc. Bộ nhớ gốc giữ nguyên (non-destructive).

Phân tích kỹ thuật
  • Cơ chế: Job bất đồng bộ — đọc memory store + session logs → pattern extraction → dedup → consolidated memory.
  • Không phải training: Memory curation ở inference-time. Agent phiên sau load consolidated memory = có "kinh nghiệm."
  • Hiệu quả: Giảm context window consumption bằng cách nén session histories dài.
Tại sao quan trọng

Implementation production đầu tiên của agent self-improvement giữa phiên mà không cần retrain. Giải quyết hạn chế cơ bản: LLM agent quên hết giữa các lần chạy. Nền tảng cho agent tích lũy chuyên môn.
