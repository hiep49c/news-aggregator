1. 🔴 Mini Shai-Hulud: Supply Chain Attack Hits AI Ecosystem Core

VERIFIED HIGH CONFIDENCE Impact: 9/10

Date: 2026-05-11 | Category: AI Security / Supply Chain

SecurityWeek • Wiz • The Hacker News

Background & Timeline

Late April 2026: First Shai-Hulud campaign hit SAP CAP packages. May 11: TeamPCP launched coordinated attack across npm + PyPI. May 12: Multiple security firms published analysis.

Key Developments

FACTS:

  • 170+ packages compromised, 404 malicious versions published
  • Targets: 42 TanStack packages, 65 UiPath, Mistral AI PyPI, OpenSearch JS, Guardrails AI
  • Attack vector: Chained 3 vulnerabilities — pull_request_target misconfig + GitHub Actions cache poisoning + OIDC token extraction from runner memory
  • Payload: 2.3MB credential stealer — harvests API keys, tokens, cloud credentials, crypto wallets, AI tool secrets
  • SLSA provenance bypass: Hijacked legitimate build pipeline → valid Sigstore certificates → packages appeared trusted
  • Exfiltration via 3 channels: fake domain, Session network (decentralized), Dune-themed GitHub repos
  • Self-propagation using stolen npm/GitHub tokens
  • Commit spoofing: Impersonates "Anthropic Claude" as commit author

ANALYSIS:

  • Most sophisticated supply chain attack targeting AI ecosystem to date
  • SLSA provenance bypass = gold standard for software integrity now insufficient
  • Session network exfiltration = takedown-resistant, new escalation
  • Mistral AI packages directly affect developers using Mistral models
  • AI tool credentials (OpenAI, Anthropic API keys) are primary targets

Impact Assessment

  • Developer security: Trust model for package registries fundamentally challenged
  • AI ecosystem: AI supply chain = high-value target
  • Enterprise: UiPath widely deployed in automation

Actionable Insights

  • Developers: Pin exact versions, audit lockfiles, enable npm audit signatures NOW
  • Enterprise: Implement allowlisting for AI packages, monitor anomalous publishes
  • Security teams: Monitor Session network exfiltration, review GitHub Actions permissions
