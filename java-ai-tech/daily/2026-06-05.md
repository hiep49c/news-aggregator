#### Tóm tắt

#### Điểm mới

#### Phân tích
Với ngân hàng đang xây dựng dịch vụ AI (chatbot, RAG tra cứu chính sách, agent nội bộ), Spring AI 2.0 là cột mốc quan trọng: nó chuẩn hóa cách tích hợp LLM trong stack Java doanh nghiệp vốn đã thống trị core banking. Tuy nhiên, ràng buộc Spring Boot 4.0 biến quyết định "dùng Spring AI 2.0" thành quyết định "migration nền tảng" — không tầm thường với hệ thống tài chính nhiều ràng buộc kiểm thử/tuân thủ.

#### Ảnh hưởng thực tế
- **Kiến trúc sư:** Cần lập lộ trình Boot 3.x → 4.0 trước khi áp dụng Spring AI 2.0; đánh giá tác động Jakarta EE 11 + Jackson 3 lên code serialization hiện hữu.
- **Đội bảo mật/vận hành:** Theo dõi EOL của Spring Boot 3.5 để tránh chạy nền tảng không còn vá lỗi.
- **Lập trình viên AI:** Chuẩn bị cho việc `ChatMemory` sẽ nhường chỗ cho Session API ở 2.1.

### 2. ⚡ Quarkus 3.36 — Quarkus Signals, Embedded SBOM, OIDC SPIFFE

#### Metadata
- **Nguồn:** Quarkus.io (official blog)
- **Ngày:** 27/05/2026 (3.36) · 03/06/2026 (bản vá 3.36.1)
- **Category:** Java Web / Microservices / Native image / Supply-chain security
- **Verification:** VERIFIED (official) | **Confidence:** HIGH | **Impact Score:** 6/10

#### Tóm tắt
Quarkus — framework Java "supersonic subatomic" tối ưu cho khởi động nhanh và native image (ảnh thực thi biên dịch sẵn) — phát hành 3.36 với extension thử nghiệm **Quarkus Signals**, **embedded dependency SBOM** (Software Bill of Materials — bản kê khai thành phần phần mềm), **xác thực OIDC SPIFFE** cho client, và hỗ trợ kiểu keystore/truststore tùy ý. Bản vá 3.36.1 ra ngày 03/06.

#### Điểm mới
- **Quarkus Signals:** cho phép các thành phần ứng dụng tương tác lỏng lẻo (loosely coupled) bằng cách phát/nhận "signal" — mô hình reactive nhẹ.
- **Embedded SBOM:** nhúng kê khai thành phần ngay trong artifact → phục vụ truy vết chuỗi cung ứng phần mềm, rất quan trọng cho ngành tài chính bị siết về supply-chain security.
- **OIDC SPIFFE:** chuẩn nhận dạng workload (SPIFFE) cho xác thực dịch vụ-tới-dịch vụ trong môi trường zero-trust.
- Nối tiếp chuỗi tính năng hiệu năng gần đây: JAR tree-shaking (3.35), PGO cho native (tối ưu theo hồ sơ chạy thật), tích hợp Project Leyden (3.32).

#### Phân tích
Hai chủ đề Quarkus theo đuổi — hiệu năng/native và bảo mật chuỗi cung ứng — trùng khớp nhu cầu của hệ thống ngân hàng hiện đại: microservices tiết kiệm RAM/khởi động nhanh (giảm chi phí hạ tầng) và khả năng chứng minh thành phần phần mềm (đáp ứng yêu cầu kiểm toán, DORA ở EU). Embedded SBOM + SPIFFE là tín hiệu Quarkus nhắm thẳng vào yêu cầu compliance của doanh nghiệp lớn.

#### Ảnh hưởng thực tế
- **Đội nền tảng:** Cân nhắc embedded SBOM để tự động hóa báo cáo thành phần khi audit.
- **Bảo mật:** OIDC SPIFFE hỗ trợ kiến trúc zero-trust giữa các vi dịch vụ.
- **Kiến trúc sư chi phí:** Native image + tree-shaking giảm dung lượng và chi phí vận hành ở quy mô.
